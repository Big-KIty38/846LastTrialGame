Не нужны для запуска игры. Автоматические механические проверки.
Для разработчика с Python и Playwright:
pip install playwright
python -m playwright install chromium
python mechanics.py
Тесты создают одноразовый контекст браузера и не трогают пользовательское
сохранение в вашем обычном браузере. Проверяют симуляцию механик,
а не все возможные действия игрока.
